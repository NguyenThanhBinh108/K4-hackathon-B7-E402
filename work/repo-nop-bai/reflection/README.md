# reflection — mỗi người 1 file

Đặt tên file theo tên mình: `vu.md`, `binh.md`, `linh.md`, `lieu.md`, `hai-dang.md`.

Mỗi file trả lời 4 ý (chấm riêng theo rubric reflection của khoá):

1. **Vai của mình trong nhóm** — cụ thể, không phải "hỗ trợ chung".
2. **Phần mình làm** — trỏ vào file/hàm/mục cụ thể. *Ai đứng tên phần nào phải giải thích được phần đó khi bị hỏi ngẫu nhiên ở CP5 — không giải thích được thì phần cá nhân liên quan 0 điểm.*
3. **AI hỗ trợ mình thế nào** — chỗ nào dùng AI, chỗ nào phải tự sửa lại vì AI làm sai.
4. **Một bài học từ case fail của chính nhóm** — lấy từ bảng kết quả trong `eval/`, không phải bài học chung chung.
